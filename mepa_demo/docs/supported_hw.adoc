= Supported Switch and PHYs

== Supported Switch and PHYs

Following are the Switches and PHYs supported for the corresponding
Switches.

=== EDSx Supported PHYs

[cols="1,1,1", options="header"]
|===
| PHY       | SKU     | Host Interface
| Malibu10G | VSC8258 | SFI
| Malibu25G | LAN80XX | SFI
|===

Below diagram illustrates the port number to channel ID mapping in LAN80XX PHY.

[ditaa]
....
        +---------------+                     +---------------+
        |             1 |                     | 3             |
        |             2 |                     | 2             |
        | Slot1 Ports 3 | ------------------->| 1 Channel ID  |
        |             4 |                     | 0             |
 EDSX	+---------------+                     +---------------+  LAN80XX
        |             5 |                     | 3             |
        |             6 |                     | 2             |
        | Slot2 Ports 7 | ------------------->| 1 Channel ID  |
        |             8 |                     | 0             |
        +---------------+                     +---------------+

....
